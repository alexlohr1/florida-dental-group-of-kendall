# Florida Dental Group — Concept Rebuild

Static multi-page website concept based on the public content architecture of floridadentalgroup.com.

## Run
Open `index.html` directly, or serve the folder with any static web server.

## Included
- English home + 5 core pages
- 12 dedicated treatment pages
- Spanish home + 5 core pages
- Shared responsive CSS/JS
- Appointment/contact forms (front-end only)
- Before/after gallery placeholders awaiting approved patient media

## Production notes
Forms require a real backend/CRM integration. Replace conceptual visual placeholders with licensed/owned practice photography. Verify all hours, financing terms, clinical claims, provider information, insurance language, privacy/HIPAA handling, accessibility, and legal copy before launch.
