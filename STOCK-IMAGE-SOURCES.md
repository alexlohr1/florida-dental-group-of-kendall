
# Florida Dental Group — Curated Stock Image Sources

All website images are stored locally in `public/images/`. Each image is loaded directly from this directory using its corresponding filename. No external image URLs or stock-image fallbacks are used.

The images are intended for commercial website use. Do not imply that people depicted endorse Florida Dental Group, and avoid presenting stock people as actual staff or patients. Patient results and team photography should use approved, authentic images.

## Local Image Loading

All images must be placed in:

`public/images/`

The website uses the exact filenames listed above to locate the corresponding image assets.

- No external image hosting is required.
- No Pexels or Unsplash URLs are used.
- English and Spanish pages share the same local image files.
- Missing images display the website's existing visual placeholder.
- Image filenames must match exactly, including capitalization and file extensions.

## Production Notes

Optimize images before adding them to the website. Use appropriately sized JPEG or WebP files to improve loading performance.

Keep original source information and licensing records separately for any third-party stock images.

All real patient photographs require appropriate authorization before publication.
